# Horizon 060

Site vitrine animé des films et documentaires de Hugues Bashengezi.

Technologies : Next.js, Tailwind CSS, Framer Motion, shadcn/ui.

## Modifier le contenu

Tout le texte, les vidéos et les liens sont dans `src/content/site.ts`.

## Lancer en local

```bash
npm install
npm run dev
```

## Mise en ligne

Le site se déploie sur Vercel : importer ce dépôt, puis cliquer sur Deploy, sans réglage particulier.
